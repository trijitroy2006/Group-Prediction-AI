# Prediction AI

An intelligent decision-support platform to predict startup and project failure risks and recommend mitigations.

## 🚀 Quick Start
To view the live application running on your local machine, click the link below:
**👉 [Open Application (http://localhost:8501)](http://localhost:8501)**

*(Note: The Streamlit server must be running on your machine for this link to work.)*

## Milestone 1

### Setup
1. Extract ZIP (or pull repository).
2. Install Python.
3. `python -m venv venv`
4. `venv\Scripts\activate` (Windows)
5. `pip install -r requirements.txt`
6. Create PostgreSQL database `ml_project` and run `database.sql`.
7. Update `password` in `database.py`.
8. `python app.py`
